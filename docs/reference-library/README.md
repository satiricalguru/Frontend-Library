## Refero coverage

The existing **1,342 Refero styles** remain searchable, with palette/typeface metadata and original links. Their DESIGN.md files, full pages and animations are not bundled here. Refero's AI-crawler restriction prevented a new deep crawl; see [source policies](../../data/source-policies.json). A style index is not a recorded landing page.

## Refresh one page

```bash
node scripts/capture-pages.mjs --id lusion-home --force
python3 scripts/build-reference-library.py
python3 scripts/validate-references.py
```

Capture prerequisites: Node 22+, Chrome/Chromium (`CHROME_PATH` on other installations), and ffmpeg. Captures run sequentially using a temporary browser profile. They include requested wheel/pointer input; no forms are submitted. Source media keeps its owner's rights.
