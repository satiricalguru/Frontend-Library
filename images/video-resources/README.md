## Use media in a landing page

Choose a clip or image only after checking the provider's current licence, attribution, commercial-use and redistribution terms. For video heroes, plan a static poster, muted inline playback, a reduced-motion alternative and accessible playback controls. Measure encoded byte size and mobile decoding cost before choosing full-viewport video. Music and sound need separate rights and a user-controlled playback path.

For a reference recreation, record the original composition, crop, duration and interaction role. A similar stock clip does not guarantee an exact visual match. Keep chosen asset URLs and licence evidence alongside the project's implementation brief.

## Refresh and validation

```bash
python3 scripts/collect-video-resources.py
python3 scripts/collect-video-resources.py --validate-only
```

Refresh resolves the upstream default branch to an immutable commit before fetching its README. To reproduce the current snapshot, pass `--commit` with the SHA in the JSON catalog; use `--date` to preserve its collection date. Only the repository metadata, README and licence are requested. Linked providers are not crawled.
