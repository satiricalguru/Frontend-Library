## At a glance

| | |
|:--|:--|
| **What it is** | A real-time, looping 90 s animated film: a red loong (Chinese dragon) coiled on a karst spire above a valley of red maples and vermilion temple halls; a white loong pours out of a storm cloud; they fight across the sky, plunge into the lake, and rise together after a pearl. |
| **Author** | [ChetasLua](https://github.com/ChetasLua), made as an answer to scottstts' "Dragon's Nest" (which used generated 3D assets; this uses none). |
| **Stack** | three.js r180 inlined into the page, no add-ons, no post-processing package, no physics engine, no audio library. WebGL 2, GLSL, Web Audio API with synthesis in a Web Worker. A small Python build script. |
| **Assets** | None. No image, model, font, HDRI or sound file, no `data:` URIs, no loaders. Every mesh, texture, shader and note is generated by code at load. |
| **Network** | None after the page opens. Runs from `file://` as well as from a server. |
| **Performance** | 60 fps at up to 3.7 megapixels on an Apple-silicon laptop GPU; adaptive resolution in six steps, down to a steady 30 fps. |
| **Size** | `index.html` ≈ 2 MB (three.js plus ~1.3 MB of source, inlined). |
| **Licence** | **None declared** (all rights reserved by default). three.js itself is MIT. Study it, link to it, credit it; don't copy its source. The [build prompt](BUILD-PROMPT.md) is written for an original reimplementation. |

## The film, beat by beat

80 bpm: 0.75 s per beat, 3 s per bar, 30 bars. Picture, effects and score are all keyed to one frozen beat sheet, so they hit together.

| Time (s) | Beat | What happens |
|--:|:--|:--|
| 0 | Open | The camera rises from just above the lake bank, behind grass and a yellow shrub, out over the lake. Layers of grass, bank, pavilions, halls and spires slide against each other before anything moves. |
| 9.0 | EMERGE | The red loong slides round the front of the spire. |
| 15.0 | DRUMS | Drums enter; red climbs and crests the spire. |
| 21.4 | CHARGE | Red inhales; its throat glows. |
| 24.0–27.0 | ROAR | Red roars fire at the sky: a challenge. |
| 27.0 | OMEN | Thunder answers; lightning inside the cloud tower; a pale rift opens. |
| 30.0 | DESCENT | The white loong breaks out of the cloud and spirals down. |
| 36.0 | FACEOFF | The two circle the spire, eye to eye. |
| 39.0–41.2 | WROAR | White roars a frost-lightning breath; red snarls back. |
| 42.0 | CLASH1 | First mid-air collision. |
| 46.5 | FIRE2 | Chase: red breathes fire across white's path (~1.6 s). |
| 49.5 | BOLT | White spits a lightning bolt; it misses red and shatters rock. |
| 51.0 | CLASH2 | Second collision: they bite, lock and entwine. |
| 57.0 | SPLASH | The entwined tumble hits the lake; they tear apart. |
| 63.0 | BEAM | Fire jet and frost-lightning jet meet head on. |
| 67.5 | BLAST | The meeting point detonates (white-out). |
| 69.0 | FINALE | Both spiral upward, chasing the pearl the blast left behind. |
| 84.0 | GONG | They vanish into the clouds. |
| 86.6 | OUT | Fade; the film loops. |

## How it's built

The source is plain scripts in `src/`, concatenated in name order and inlined with three.js into one page by `tools/build.py`.

| Module | What it makes |
|:--|:--|
| `00_util` | Keyed curves, improved Perlin and cellular noise on the CPU, geometry merge/bake helpers, tubes along sampled points |
| `05_glsl` | Shared shader chunks: analytic dusk sky, height fog, aerial haze, drifting cloud shadows, wind; one "daylight" state every material reads (patched in via `onBeforeCompile`) |
| `10_sdf`, `15_tex` | A signed-distance sculpting kit with a surface-nets mesher (heads, teeth, antlers); GPU-baked tiling detail maps (fractures, bedding planes) and canvas-drawn leaves |
| `20_sky` | Cumulus ray-marched **once at load** into four fisheye layers that drift at their own rates; flow fields, standing-wave swell, the storm tower, the rift, rain |
| `30_rock` | Jointed-limestone karst spires and cliffs from displaced parametric surfaces; one integer-hash "block field" evaluated on the CPU (mesh) and in the fragment shader (crisp joints at any distance) |
| `35_arch` | Timber-frame temple halls, gate and pavilions written into one buffer per material; lanterns as pendulums; cloth |
| `40_flora` | Red maples, Huangshan pines, plum blossom, shrubs, ferns, grass, spider lilies; leaf sprays on a data atlas lit through the leaf (translucency) |
| `58_dlook` | How a loong looks: palettes (red, white), plate-scale shader, sculpted head, eyes, mouth, antlers, mane, whiskers, legs, wetness |
| `60_dragon` | How a loong moves: a 150–172 m body gliding on a rail, with acting layered on top; the choreography built from named world anchors |
| `66_wake` | How the world answers: a live wind field from 8 points down each body plus the pressure fronts of roars, clashes, the bolt, the splash and the blast |
| `68_water` | Lake with a true planar mirror, depth and shore from a baked bed map, current, ripples, waterfalls, bow sheets, the splash |
| `70_fx` | Fire, frost, lightning, the beam ball, the blast, spray, shed water, the pearl, the aftermath |
| `72_air` | Mist streaming along baked stream lines, banner clouds, cloud falls, birds, leaves, smoke, fireflies, gust fronts |
| `80_post` | MSAA HDR scene → ambient occlusion → soft FX layer → 4-step bloom → sun shafts at quarter resolution → grade and lens |
| `85_audio` | The score and every sound effect, synthesised in a Worker: red = erhu, dizi, guzheng, taiko, gong in G minor pentatonic; white = bowed glass, xiao and bells on a B–F♯–E–D motif |
| `88_film` | The frozen beat sheet, the camera crane, wind and storm controls, grade pulses |
| `90_main` | Boot and staged loader, lights, render loop, frame pacing, adaptive quality, lost-context recovery, controls |

### Ideas worth stealing (as techniques, not code)

1. **Everything is a pure function of film time.** Any frame can be rendered on its own, in any order, so seeking, looping, pausing and exact-frame testing come for free. Effects that need memory (lake rings, torn leaves, swinging lanterns) read tables built once at load.
2. **One frozen beat sheet drives picture, FX and sound.** Timing is data, so the score and the cuts can't drift apart.
3. **Bake expensive work at load.** Clouds are ray-marched once into drifting layers; detail maps are baked on the GPU; then display time only composites and flows them.
4. **The same function on CPU and GPU.** The rock's block field displaces the mesh and is re-evaluated per pixel at the undisplaced position, so drawn joints sit exactly on the geometric steps.
5. **A camera "crane", not a free camera.** Position keys through a monotone cubic (it never stops dead between marks), look-at weights blended between subjects, keyed framing offsets for thirds and headroom, plus handheld breath and shake.
6. **The world reacts.** A wake field pushes plants, dust, mist and water as the bodies pass; pressure fronts travel outward at finite speed.
7. **Graceful degradation.** Adaptive pixel count with GPU timer queries, a lower tier that thins instanced plants evenly, and a rebuild at the same film time after a lost WebGL context.
